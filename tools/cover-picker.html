앨범 아트 검토 도구

이 페이지는 로컬에서만 사용하는 관리자용 도구입니다 (사이트에는 포함되지 않음). 곡마다 iTunes에서 후보 이미지를 찾아 보여주면, 직접 눈으로 확인하고 고른 이미지만 covers/ 폴더에 저장하고 sscdbg.json의 image 필드에 반영합니다. 한 번 저장된 곡은 다음에 다시 열어도 건너뜁니다.

Chrome 또는 Edge 데스크톱에서 열면 프로젝트 폴더를 선택해 자동으로 저장할 수 있고, 다른 브라우저에서는 파일을 하나씩 다운로드하는 방식으로 대신 동작합니다.

⚠️ 이 파일을 더블클릭해서 바로 열면(file://로 열리면) iTunes가 검색 요청을 전부 거부할 수 있습니다. 아래처럼 아주 간단한 로컬 서버로 실행해주세요:

tools 폴더 안에서 터미널을 열고,
Python이 있다면: python3 -m http.server 8000
Node.js가 있다면: npx serve .
실행한 뒤 브라우저에서 http://localhost:8000/cover-picker.html (또는 안내된 주소)로 접속하세요.
iTunes 연결 확인 중...
이 브라우저는 폴더에 직접 저장하는 기능(File System Access API)을 지원하지 않아요. 대신 아래에서 sscdbg.json 파일을 선택해서 불러오세요. 이미지는 개별적으로 다운로드되며, 끝나면 갱신된 sscdbg.json을 다운로드할 수 있어요. 다운로드된 이미지는 프로젝트의 covers/ 폴더로 직접 옮겨주세요.
